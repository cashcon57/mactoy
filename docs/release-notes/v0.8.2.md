# Mactoy v0.8.2: Fixes

Three fixes from your reports, all in the new window from v0.8.1.

## Adding images in Manage Disk no longer freezes the window

Picking several large ISOs in **Manage Disk > Add ISO…** froze Mactoy until the last one was copied ([#45](https://github.com/cashcon57/mactoy/issues/45)). Copies now run in the background:

- A progress card shows the file being copied, how many are left, and how much is done, with **Cancel**.
- Each image is copied under a temporary name and only gets its real name once it's complete and on the drive, so a cancelled or interrupted copy never leaves a half-written image in Ventoy's boot menu.
- Images that don't fit are refused before anything is copied, and so are images of 4 GB or more on a FAT-formatted drive. A file that's already on the drive is skipped, never replaced.
- Install, Update and Flash Image wait while files are copied, so a drive can't be erased mid-copy. Quitting during a copy asks first.

## Manage Disk no longer shows an empty window

With a drive selected that has no Ventoy volume, Manage Disk showed an empty window, without even the drive list. The window was sizing itself from its own text, and ended up thousands of points tall. That's fixed, and the automatic screenshot checks now catch it.

## A likely fix for a crash when starting Install or Update

On macOS 27.2, Mactoy 0.8.1 could crash right after you confirmed Install or Update ([#46](https://github.com/cashcon57/mactoy/issues/46)). Nothing was written to the drive when it happened. The crash is in the same window sizing as the empty-window bug above, and that is fixed, together with two more changes that take away what most likely set it off. It doesn't happen on macOS 27.0, so if you saw it, please tell us on #46 whether 0.8.2 fixes it.

## Also

- **View > Show Sidebar** brings the drive list back if it's ever hidden.
- Changing a drive's boot theme checks first that it's still the same drive.

## Install

- **Homebrew:** `brew upgrade --cask mactoy`, or `brew install --cask mactoy`.
- **DMG:** download `Mactoy-0.8.2.dmg` below and drag **Mactoy** to Applications, replacing the old copy.

The helper didn't change, so macOS shouldn't ask you to approve it again.

## How this was tested

- 743 automated tests, including the new copier on its own and in the app.
- Copies onto real exFAT and FAT32 disk images: byte for byte identical, too-big batches refused, Cancel leaves nothing behind, a different drive mounted in the same place refused.
- Screenshots of every screen on macOS 15 and 26, now including the smallest window size, with an automatic check that the window's layout fits.
- Three rounds of independent code review for each change.

If anything looks wrong, please open an issue.
