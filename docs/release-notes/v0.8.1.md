# Mactoy v0.8.1: Liquid Glass

Mactoy has always been meant to look like a macOS 26 app, but on macOS 26 it was drawn in the older, opaque style. This release fixes that and redoes the window around it.

## Liquid Glass, for real

The build recorded the oldest macOS Mactoy supports (13.5) as the SDK it was built with, and macOS 26 uses that to decide between Liquid Glass and its older look. Every release so far got the older look. The build now records the SDK it really used. Nothing changes about which Macs can run Mactoy: macOS 13.5 or later, Apple Silicon or Intel.

## A new window

- **One toolbar.** The title bar and the mode buttons are now a single glass toolbar, with the mode picker in the middle.
- **See-through.** The sidebar and the content show what's behind the window, blurred. With Reduce Transparency on, they're opaque.
- **A floating main button.** Install Ventoy, Flash Image and the rest float over the content, with no bar behind them.
- **Support on Ko-fi** moved to the bottom of the sidebar, as a glass button with a drawn Ko-fi mug.

On macOS 13 to 15 the window uses the standard translucent sidebar and toolbar, and the main button sits in a translucent bar at the bottom. Everything else works the same.

## Install

- **Homebrew:** `brew upgrade --cask mactoy`, or `brew install --cask mactoy`.
- **DMG:** download `Mactoy-0.8.1.dmg` below and drag **Mactoy** to Applications, replacing the old copy.

The helper didn't change, so macOS shouldn't ask you to approve it again.

## How this was tested

- **A new CI job** runs the app in a screenshot mode on macOS 14, 15 and 26 and saves every screen in light and dark (each mode, progress, failure, success, the erase confirmation, no drives). From now on, a pull request that changes the app gets these screenshots, so it can be looked at on older macOS without a Mac running it.
- That job also caught a crash in debug builds run on a different Mac. Releases weren't affected, and the cause (the old Ko-fi badge image) is gone.
- All 717 automated tests pass. The disk-writing code didn't change.

If anything looks wrong, please open an issue.

**SHA256 of `Mactoy-0.8.1.dmg`** is published below the release assets.
