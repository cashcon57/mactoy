# Mactoy v0.5.1 — the "remove the helper" checkbox works

A small fix release.

## What's fixed

### "Remove the helper when done" now does what it says

The approval sheet Mactoy shows before its first install has a checkbox to remove its background helper afterwards, ticked by default. It never worked: once you approved the helper, Mactoy quietly unticked it, so the helper always stayed registered. Now your choice holds. With the box ticked, the helper is removed when the install, update or flash finishes, and you approve it again next time. Untick it to keep the helper and skip the approval on later runs.

The checkbox is now labelled **Remove the helper when done**, and the sheet's wording no longer promises a one-time approval when the default removes the helper.

### Update Ventoy no longer gets stuck without the helper

Update Ventoy reads the stick through the helper to see which Ventoy version is on it. With the helper removed, that check failed, and the Update button stayed disabled. The hint even suggested a fresh install, which would erase the stick.

The hint now has a **Set Up Helper…** button. It shows the usual approval sheet; once you approve, Mactoy checks the stick again and you can update. Setting up the helper this way never starts an install, update or flash on its own. That includes a failed one waiting for you to press Retry, and it holds even if you cancel partway through.

## Install

```sh
# Download Mactoy-0.5.1.dmg from the release assets.
open Mactoy-0.5.1.dmg
# Drag Mactoy.app into /Applications, replacing the old version.
```

Apple-notarized. The helper itself is unchanged from v0.5.0, so updating doesn't make you approve it again.

## How this was tested

- 144 automated tests, 16 of them new. Each fix was checked by re-introducing the bug and confirming a test fails.
- Several rounds of independent code review. Two of them caught ways the first version of the Set Up Helper button could restart a failed install after you approved the helper. Both are fixed and covered by tests.
